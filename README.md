
# Nandini GIS Solutions

## Professional GIS Services Website

Nandini GIS Solutions is a responsive professional services website developed as part of the Week 4 Web Development Project.

The website presents GIS, Remote Sensing, Spatial Analysis, Web GIS services, projects, professional information, and contact details.

## Project Objectives

- Create a complete multi-page professional website.
- Implement responsive web design.
- Use HTML5, CSS3, and JavaScript.
- Add interactive website features.
- Implement contact form validation.
- Organize files into separate folders.
- Deploy the website using GitHub Pages.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Visual Studio Code
- GitHub
- GitHub Pages

## Website Pages

### Home
Introduction to Nandini GIS Solutions and an overview of the services.

### About
Information about my GIS background, interests, and skills.

### Services
Information about GIS Mapping, Spatial Analysis, Remote Sensing, and Web GIS services.

### Projects
Showcase of GIS and Web GIS projects.

### Contact
Contact information and an interactive contact form.
